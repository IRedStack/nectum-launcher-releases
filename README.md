# Nectum Legacy Launcher

Repository pubblica dedicata ai pacchetti compilati del launcher Windows per **Nectum Legacy**, server HogwartsMP di Hogwarts Legacy.

## Download

I pacchetti per i giocatori vengono distribuiti nella sezione [Releases](https://github.com/IRedStack/nectum-launcher-releases/releases). Il pacchetto **0.2.1** è stato compilato e verificato; l'allegato ZIP deve ancora essere caricato. Questa pagina non dichiara una Release già disponibile.

Quando disponibile, scarica `Nectum-Legacy-Launcher-0.2.1.zip`, estrai tutta la cartella e apri `Nectum.Legacy.Launcher.exe`. Scegli il microfono e premi **Gioca**. È necessario avere Hogwarts Legacy e il client ufficiale HogwartsMP completo già funzionante.

Il riconoscimento vocale parte in background con il gioco. **Lumos** accende e **Nox** spegne: il personaggio deve avere imparato Lumos. L'audio viene elaborato sul PC; il server riceve i comandi riconosciuti.

## Contenuto

Questa repository contiene documentazione di distribuzione e verifiche dei pacchetti. Il codice del launcher e della risorsa server è conservato separatamente e non viene pubblicato qui. Gli archivi automatici “Source code” generati da GitHub per questa repository contengono soltanto questi file pubblici: il programma si scarica dall'allegato ZIP della Release.

Il launcher attuale non installa automaticamente aggiornamenti da GitHub. Le nuove versioni vanno scaricate ed estratte separatamente.
